# commit-live-demo

Demo of [commit-live](https://github.com/fitzyracing1/commit-live). `.github/workflows/live.yml` is the README's 5-line
quickstart, unchanged.

- Every push: `npm test` → ● lit / ○ dark commit status; lit commits get a preview at
  https://fitzyracing1.github.io/commit-live-demo/c/&lt;sha&gt;/
- Live site (the commit made live with go-live): https://fitzyracing1.github.io/commit-live-demo/ — `live.json` says which.
